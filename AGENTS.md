# Agent guidance

Keep always-loaded guidance small. Read detailed procedures only when needed:

- Run a local ACE audit, proposal, or verification: `skills/agentic-cost-optimization/SKILL.md`.
- Integrate with an editor or coding agent: `docs/agent-integration.md`.
- Operate or recover the local CLI: `RUNBOOK.md`.
- Roll out organizational practice: `docs/enterprise-adoption.md`.

ACE is local and review-only. Do not auto-apply its candidate diff. Preserve the legacy scripts in `scripts/` and use `scripts/ace.py --help` for current CLI options.
